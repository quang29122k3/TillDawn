**Usage**
**1. In student interface:**
   - Return books: student can return their books.
   - Borrow books: Student can borrow books in the library by click on the book and then click on the icon borrow.
   - Search for a book: Enter the book title, author, or genre into the search bar and click Search to find matching books.
   - Google API books: can search for a book in the google api library
   - Change user information: click on the image on the left-corner in ther interface and user can change their information.

     
**2. In admin interface:**
   - Add books: Click the Add Book button to add a new book to the library.
   - Edit books: Select a book from the list and click the Edit Book button to modify the book details.
   - Delete books:  Select a book and click the Delete Book button  to remove it from the library.
   - Return books: student can return their books.
   - Borrow books: Student can borrow books in the library by click on the book and then click on the icon borrow.

   - Google API books: can search for a book in the google api library

**3. In login interface:**
   - User can register for their account
   - Admin can register for their account (require admin code)
   - Forgot password: user can change their password when they forget and a authentication code will send to their email that their register.
   - Login: Login in the library by click on the login button.
